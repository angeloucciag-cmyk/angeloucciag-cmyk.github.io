# angeloucciag-cmyk.github.io

Personal robotics portfolio of Angelo Gregucci, served with GitHub Pages.

**Live site:** https://angeloucciag-cmyk.github.io

It is a static single-page site (`index.html`) with no build step. To add a project, add an `<article class="card">` block in `index.html` and put its image in `assets/img/`.
